# iOS App Intents (Phase I)

A placeholder `OpenAppiIntent` lives in `AppiIOS/AppiIOS/AppiIntents.swift`.

It only opens this Appi app. It does **not** control other iPhone apps, Safari,
Files, Contacts, or the system assistant. Those remain **OS Restricted**.

Future work may add Shortcuts, URL schemes, notifications, and files the user
explicitly shares — still gated by Guardian on the cloud brain.
